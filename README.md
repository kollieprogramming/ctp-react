# React Practice Portfolio

A collection of React practical exercises (TP02 → TP20) created while learning React.js, JSX, components, props, state, forms, APIs, and class components.

## Technologies

- React.js
- JavaScript
- JSX
- CSS
- React Hooks
- Axios
- REST API
